# מילון הנתונים ושחזור M2

[טבלת הניתוח](../data/nextcup_days.csv) נבנתה מנתוני NHANES של אוגוסט 2021 עד אוגוסט 2023. [סקר 2017–2018](../data/README.md) שימש לגרסת M1. המחזורים מנותחים בנפרד.

| שדות | פירוש וקידוד |
|---|---|
| `person_id`, `recall_day` | מזהה ציבורי SEQN ויום ריאיון תזונה 1 או 2. זהו מפתח השורה. הימים אינם בהכרח רצופים. |
| `weekday` | יום בשבוע של דיווח התזונה, 1 ליום ראשון עד 7 לשבת. |
| `age`, `sex` | גיל בשנים, 80 ומעלה מקודדים 80. המין כפי שקודד ב־DEMO הוא 1 לזכר ו־2 לנקבה. |
| `usual_sleep_hours` | SLD012, שעות השינה הרגילות בימי עבודה או לימודים. משמש לתיאור המדגם ומקורו בשאלון על הרגלים. |
| `fatigue_frequency` | DPQ040, תדירות עייפות בשבועיים הקודמים. 0 כלל לא, 1 במספר ימים, 2 ביותר ממחצית הימים, 3 כמעט בכל יום. |
| `events`, `coffee_events` | מספר דקות צריכה נבדלות ביום, בכלל מקורות הקפאין או בקפה בלבד. |
| `first_min`, `second_min`, `last_min` | מועד האירוע הראשון, השני והאחרון בדקות מחצות. באירוע יחיד הראשון והאחרון זהים. |
| `gap_min` | הפרש בין second_min ל־first_min. לכל יום יש לכל היותר תצפית יעד אחת גם כאשר דווחו שלושה אירועים או יותר. |
| `total_mg` | סך קפאין יומי במ״ג מכל הפריטים הזכאים. |
| `coffee_first_min`, `coffee_second_min`, `coffee_last_min`, `coffee_gap_min`, `coffee_total_mg` | אותן הגדרות לאחר סינון לפריטי קטגוריית Coffee עם כמות קפאין חיובית. קפה דל קפאין עם כמות מדווחת חיובית יכול להיכלל. |

## מקורות

- תזמון וקפאין לפריט מזון, ושיטת הריאיון. [יום ראשון](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DR1IFF_L.htm) · [יום שני](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DR2IFF_L.htm)
- אמינות הריאיון, יום בשבוע ובקרת סך הקפאין. [סיכום יום ראשון](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DR1TOT_L.htm) · [סיכום יום שני](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DR2TOT_L.htm)
- הגדרות גיל, שינה ועייפות. [DEMO](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DEMO_L.htm) · [SLQ](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/SLQ_L.htm) · [DPQ](https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles/DPQ_L.htm)
- מיפוי קפה. מתוך הגיליון הראשון בקובץ USDA נבחרו 109 שורות שבהן `category_number == 7302`. עמודות הקוד והתיאור נשמרו ב־[`coffee_codes.csv`](../data/coffee_codes.csv) בסדר קוד עולה. [קובץ הסיווג המקורי](https://www.ars.usda.gov/ARSUserFiles/80400530/apps/WWEIA_August2021_August2023_foodcat_FNDDS.xlsx)

## ביקורת נתונים

בקובצי הפריטים נבדקו מפתח משתתף–שורת מזון בתוך כל יום, סטטוס דיווח, תכולת קפאין שלילית או חסרה ושעה מחוץ ליממה. הקוד עוצר אם בדיקה נכשלת או אם סכום הפריטים סותר את הסך הרשמי. בטבלה הסופית שדות מזהה, גיל, יום, ספירות וכמויות מלאים לכל הרשומות. לכלל המקורות חסרה שעת התחלה ב־1,100 ימים ויעד ב־3,920 ימים. בקפה בלבד חסרה שעת התחלה ב־3,447 ימים ויעד ב־7,529 ימים. שדות הזמן האחרים נבדקים ביחס לספירות האירועים.

לצורך ביקורת נפרדת שוחזרו רשימות של דקות ייחודיות עם קפאין מכל שורות המקור, ולאחר מכן הן מוינו ונלקחו שני האיברים הראשונים. נמצאו **אפס הבדלים** בספירה, בזמן הראשון, בזמן השני וביעד בכל 8,568 הימים בשתי הגדרות המקור. המפתחות וספירות האירועים נמצאו תואמים גם לקובץ העבודה היומי שהצוות הכין לפני M2.

SHA-256 של קובץ ה־CSV לאחר שחזור על Windows בשתי סביבות Python עצמאיות, 3.12 ו־3.13:

```text
072cc130ed7b5aea08c8c66f39a0ce7a4aa160dd407575930b5b3aa2eda87a6e
```

לבדיקה ידנית ב־PowerShell מריצים `Get-FileHash data/nextcup_days.csv`. השחזור כותב UTF-8 עם ירידת שורה LF. הפיצול לאימון ולמבחן משייך משתתף למבחן אם הערך המספרי של שמונת התווים הראשונים של SHA-256 של המזהה העשרוני מתחלק ב־5. כך ניתן לשחזר את מבחן M3 בלי תלות בסדר השורות.
